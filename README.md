🎙️ Elisa Voice Assistant

Elisa is an intelligent voice-controlled personal assistant built using Python.
It listens to your voice commands, understands them, and performs various system and online tasks—just like a mini Jarvis!

🚀 Features

✅ Voice Recognition: Understands and processes user voice commands.
✅ Text-to-Speech: Speaks responses using natural speech synthesis.
✅ App Control: Opens or closes applications on your system.
✅ Web Automation: Performs Google searches, opens websites, and fetches Wikipedia summaries.
✅ Media Playback: Plays music, videos, or YouTube content.
✅ System Commands: Controls basic system functions like shutdown, restart, or volume.
✅ Auto Greeting: Welcomes you intelligently based on the time of day.
✅ Frontend Interface: A web-based interface to display Elisa’s responses and visualize commands.
